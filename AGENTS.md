# Project rules

Read docs/vision.md and docs/architecture.md before changing this project. Limux owns functional behaviour; themes own appearance. Never change shortcuts, hardware support or input settings when applying a theme. Preserve working T2 audio, Touch Bar, backlight, Wi-Fi, trackpad and display settings. Inspect actual configuration before editing; back up changes and verify replacements before removing anything. Maintain one canonical active configuration per component, avoid duplicate autostart and unused dependencies, and preserve shared dependencies. Keep generated outputs separate from human-maintained functionality. Scripts must be predictable, idempotent, validated and recoverable. Never commit secrets or personal data. Never push or create a remote without explicit approval. Do not claim a command exists until implemented and tested.
