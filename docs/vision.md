# Limux vision

Limux is an opinionated, cohesive desktop environment built from existing Linux components, not a distribution or a collection of unrelated dotfiles. It combines the comfort of classic Macintosh interfaces with the flexibility, speed and keyboard-driven strengths of modern Wayland. Limux is the product and enduring design language; Rhapsody is its first theme.

Braun industrial design is fundamental to Limux, particularly the ET 66 calculator by Dietrich Lubs and Dieter Rams. Its current expression is disciplined proportions, precise typography and alignment, clear material relationships and purposeful colour. Controls should communicate use and state without copying historical decoration or turning every element into a calculator key.

Rhapsody draws from Macintosh Platinum's light system cohesion, Apple Rhapsody's developer character and NeXTSTEP's utility and hierarchy. It is a contemporary interpretation. Porcelain, cool grey, metal and graphite define its material hierarchy; lavender is almost imperceptible within neutral greys. State colours have separate purposes. The approved Quiet Workspace Strip and Foot block cursor share the warm orange token through independent semantic roles. The original yellow workspace concept and previous yellow Foot cursor remain historical references; The launcher, Command menu and file window share one graphite selection.

The system environment is predominantly light: Mangobar, Rofi, the Thunar file window, notifications, system controls and window chrome. Foot and appropriate developer tools are deliberately dark and coordinated through typography, spacing, borders and contrast.

The [canonical design language](design-language.md) records the current direction and six foundation colours. Read it with the [original visual reference](references/braun-interface-concept.png), [archived source](references/original-design-reference.md) and [decision log](design-decisions.md). Approved component baselines are specific; Inter is the system interface face and Adwaita Mono the terminal face. Future component treatments remain open.

Limux owns shortcuts, Command-key behaviour, workspaces, gestures, launchers, clipboard and window management. Themes own presentation while expressing Limux's underlying design principles. Theme changes must never alter input, hardware or essential window-management behaviour. Follow the [architecture](architecture.md): shared tokens, generated styling, separate functionality, one canonical active configuration per component, no stale dependencies or configuration clutter, and Git history for recovery.
