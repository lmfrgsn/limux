# Limux vision

Limux is an opinionated, cohesive desktop environment built from existing Linux components, not a distribution or a collection of unrelated dotfiles. It combines the comfort of classic Macintosh interfaces with the flexibility, speed and keyboard-driven strengths of modern Wayland. Limux is the product and enduring design language; Rhapsody is its first theme.

Braun industrial design is fundamental to Limux, particularly the ET 66 calculator by Dietrich Lubs and Dieter Rams. Precise typography, spacing, alignment and proportions; recessed information and input surfaces; subtle raised/depressed controls; defined borders and purposeful colour should make the desktop feel like a beautifully engineered instrument. This is functional physical precision without exaggerated skeuomorphism or making every element a calculator key.

Rhapsody combines Macintosh Platinum's light chrome, compact controls and cohesive system experience; Apple Rhapsody's transition from classic Macintosh personality to a modern developer system; and NeXTSTEP's functional precision, utility and strong hierarchy. It is a contemporary reinterpretation. Porcelain, cool grey, metal and graphite define its material hierarchy. Lavender is almost imperceptible within neutral greys. Sparse signal yellow, green and red communicate meaningful selection, positive/functional status and destructive/error/urgent states. The original active workspace is yellow; a general emphasis token does not override that decision.

The system environment is predominantly light: Mangobar, Rofi, Mako, GTK/Thunar, controls and window chrome. Foot, terminal-based Codex and appropriate developer tools are deliberately dark, coordinated through typography, spacing, borders, contrast and semantic accents. Existing live configurations are preserved until separately authorized implementation.

The [canonical design language](design-language.md) reconciles the six initial Rhapsody foundation colours with the fuller Braun material and signal hierarchy, and preserves concrete component examples. Read it with the [original visual reference](references/braun-interface-concept.png) and [archived source](references/original-design-reference.md). Final typography (IBM Plex versus Inter), exact reconciled colours, geometry and component treatments remain open; the [decision log](design-decisions.md) distinguishes established direction from experiments and records implementation discrepancies.

Limux owns shortcuts, Command-key behaviour, workspaces, gestures, launchers, clipboard and window management. Themes own presentation while expressing Limux's underlying design principles. Theme changes must never alter input, hardware or essential window-management behaviour. Follow the [architecture](architecture.md): shared tokens, generated styling, separate functionality, one canonical active configuration per component, no stale dependencies or configuration clutter, and Git history for recovery.
